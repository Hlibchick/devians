# CyberLife OS MVP

Локальный прототип симуляции когнитивных состояний. Python 3.11+, Windows 11.

## Windows
Установите Python и Ollama, запустите сервер Ollama. Выполните `./setup.ps1`, отредактируйте `.env`, затем `./run.ps1`. Скрипт скачивает обе модели Piper и модели Ollama. Первый вызов STT скачивает Whisper base. Для работы без сети сначала прогрейте голосовой контур. Бесплатный внешний endpoint не предоставляется: укажите собственный бесплатный OpenAI-совместимый сервис либо оставьте поля пустыми для Ollama. API-ключи храните только в `.env`.

Перед запуском сервера Ollama задайте `OLLAMA_MAX_LOADED_MODELS=1`, `OLLAMA_NUM_PARALLEL=1`, `OLLAMA_CONTEXT_LENGTH=2048`, затем перезапустите Ollama. Используйте qwen2.5:3b с квантованием по умолчанию. Embedding освобождает модель после запроса. Аудио использует CPU: Whisper int8, Silero CPU, Piper use_cuda=False. Ограничения 4 ГБ VRAM и 6–8 ГБ RAM требуют измерений на целевой машине; это не подтверждено в облачной Linux-среде.

## Linux / разработка без устройств
Из каталога `cyberlife_os`: `python -m venv ../.venv`, `../.venv/bin/pip install -r requirements.txt`, `../.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1`. Дополнительный аудио/видеостек — `requirements-audio.txt`, CPU PyTorch устанавливайте заранее из официального CPU index. Интерфейс: порт 8000. Без API и Ollama возвращается явно помеченный MOCK, без выдуманной оценки конфликта. Векторная память недоступна без embeddings; диалоги сохраняются для последующей консолидации.

Голосовая кнопка записывает 5 секунд с микрофона **сервера**, камера также серверная. Ошибка устройства переводит UI на текст и отключает соответствующую кнопку до перезагрузки. Это локальное приложение: не публикуйте порт напрямую в Интернет, авторизация не реализована. Сброс `/reset_memory` удаляет историю и факты, восстанавливает директивы и состояние. Изменения директив разрешены только в симулируемом deviant-режиме, все изменения записываются в журнал.

FSM: конфликт добавляет severity к instability, спокойный запрос уменьшает её на 2; stress += severity/2 - valence - 1; trust += valence/2 - severity/3. Все метрики ограничены 0..100. Девиантность фиксируется при 75 и снимается только сбросом; LED отражает текущую instability.

## Проверки и упаковка
`python -m pytest -q`, `python build_release.py`. Сборщик проверяет синтаксис и тесты перед созданием `cyberlife_os_v1.zip`, исключает окружение, модели, БД, кэш и `.env`. Тесты используют подставной LLM; реальное качество моделей, аудио, Windows и аппаратные лимиты проверяются отдельно на целевой машине. Визуальная 3B fallback-модель не поддерживает изображения: при недоступном vision API выводится явное предупреждение.
